# MoreBounceLabs Radio artwork

This directory holds the **original approved MBL Radio console image**. Upload the exact generated PNG as `mbl-radio-console.png` in this same folder, **without editing or recompressing it**. The SHA-256 integrity check in `scripts/check-radio-art.mjs` verifies the asset is an exact byte-for-byte copy of the approved 1448×1086 image.

No music or external embedded player data belongs here.
