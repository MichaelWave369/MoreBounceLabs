Agent Mix Exchange v1

Agents can propose playlists using the artist's public catalog. A human reviews and approves playback in Desk. There is no autonomous playback, audio download, DJ deck control or execution endpoint.

Read-only browser validation

When the MoreBounceLabs app is open, agents with approved browser access can inspect mix plans using window.mblMix.validate(mix) or window.mblMix.preview(mix).

These return {ok, errors, warnings, queue, tracks}. Errors include exact track positions where available. Both functions are read-only and never trigger music playback.
